# Curso Desarrollo Web — Entregas

Repositorio con las entregas del curso "Ciencias de la Computación 3: Desarrollo Web" (CREA/Schoology).

## Línea de trabajo

El curso tiene dos tipos de entregas:

1. **Tareas puntuales** — prácticas y laboratorios de cada módulo, identificadas por su número.
2. **Proyecto continuo: OA gamificado** — se construye entrega a entrega a lo largo de todo el curso (M1 → M10). Cada módulo agrega una capa tecnológica al mismo producto: HTML (M1), CSS (M2), JavaScript (M3), backend (M6), etc. La evolución se documenta en [oa-gamificado/](oa-gamificado/).
