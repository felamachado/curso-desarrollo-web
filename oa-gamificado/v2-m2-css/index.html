¿Qué es una página web?

Una página web es un archivo de texto con instrucciones. El navegador lee esas instrucciones y dibuja la página. Las instrucciones se llaman etiquetas HTML.

Como un equipo de fútbol, toda página tiene una formación: cada jugador (etiqueta) ocupa su posición.

La Formación: las 4 partes principales

Como DT, tenés que ubicar a cada jugador en su posición:

1. El escudo y la camiseta (<header>)

Es la parte de arriba de la página. Aquí va el título del sitio o el logo. Es lo primero que ve el visitante — como el escudo que identifica al club.

Ejemplo: El nombre de tu blog o el logo de una tienda.

2. El mediocampo (<nav>)

Es el menú para ir a otras páginas. Tiene enlaces como "Inicio", "Sobre mí", "Contacto". Como los volantes, conecta todo el equipo y ayuda a moverse por el sitio.

Ejemplo: Una barra con botones para ir a distintas secciones.

3. La delantera (<main>)

Es el centro de la página. Aquí va la información importante: artículos, textos, imágenes, videos. Es el ataque: lo que define el partido.

Ejemplo: El texto que estás leyendo ahora está en el main.

4. La defensa y el arquero (<footer>)

Es la parte de abajo. Aquí va el copyright, datos de contacto, redes sociales. Como la defensa, sostiene al equipo y cierra la página.

Ejemplo: "© 2026 Mi sitio - Contacto: email@ejemplo.com"

🏆 Actividades para practicar

Actividad 1: Opción múltiple

Pregunta: ¿Qué etiqueta se usa para el contenido principal de la página (la delantera)?

  • A) <header>
  • B) <nav>
  • C) <main> (correcta)
  • D) <footer>

Retroalimentación:

  • Correcta (C): ¡Gol! <main> es donde va el contenido principal.
  • Incorrecta (A): <header> es el escudo, arriba de todo.
  • Incorrecta (B): <nav> es el mediocampo, el menú.
  • Incorrecta (D): <footer> es la defensa, abajo de todo.

Actividad 2: Completar el código

Completá las etiquetas que faltan para armar la formación:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi página</title>
</head>
<body>
    <______>Título del sitio</______>
    <______>Menú: Inicio | Contacto</______>
    <______>Contenido principal aquí</______>
    <______>© 2026 - Mi sitio</______>
</body>
</html>

Respuestas: header / header · nav / nav · main / main · footer / footer

Retroalimentación:

  • Todo correcto: ¡Formación perfecta! Recordaste las 4 partes en orden.
  • Algunas malas: Revisá el orden: header → nav → main → footer.
  • Ninguna correcta: Volvé a leer la explicación de las 4 partes.
